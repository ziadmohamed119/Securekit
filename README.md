# SecureKit

A small console security toolkit written in C++ as a university project.

## Features
- **Password strength checker**: scores a password from 0 to 6 (length, upper/lower case, digits, symbols, common-password check)
- **Password generator**: creates random passwords with at least one lowercase, uppercase, digit, and symbol
- **Caesar cipher**: encrypt and decrypt text with a numeric key

## Concepts used
Object-oriented programming (classes, encapsulation), STL (string, vector), random library, input validation, menu-driven interface.

## How to run
g++ -std=c++17 SecureKit.cpp -o securekit
./securekit
